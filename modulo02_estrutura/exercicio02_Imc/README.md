# 📌 Cálculo IMC

> **Módulo:** Estrutura de Controle em Java
> 
> 
> **Linguagem:** Java (JDK 21+)
> 

---

## 🎯 Enunciado

Desenvolva um algoritmo que receba a altura e o peso do usuário, calcule seu IMC e exiba o resultado seguindo os seguintes intervalos:

- Se for menor ou igual a 18,5 "Abaixo do peso";
- se por entre 18,6 e 24,9 “Peso ideal”;
- Se for entre 25,0 e 29,9 "Levemente acima do peso";
- Se entre 30,0 e 34,9 “Obesidade Grau I”;
- Se for entre 35,0 e 39,9 “Obesidade Grau II (Severa)”;
- Se for maior ou igual a 40,0 “Obesidade III (Mórbida)”;

Use a seguinte fórmula para o cálculo: IMC = peso/(altura * altura)

---

## 💻 Conceitos & Tecnologias Aplicados

- **Entrada e Saída de Dados:** Uso da classe `Scanner` e exibição da mensagem com `println`
- **Operações Matemáticas:** Cálculo do IMC usando operações aritméticas simples e uso do laço `if/else` para exibir a mensagem de acordo com o resultado

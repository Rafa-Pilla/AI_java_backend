# 📌 Tabuada

> **Módulo:** Estrutura de Controle em Java
> 
> 
> **Linguagem:** Java (JDK 21+)
> 

---

## 🎯 Enunciado

Desenvolva um algoritmo que receba um número e seja a tabuada de 1 até 10

---

## 💻 Conceitos & Tecnologias Aplicados

- **Entrada e Saída de Dados:** Uso da classe `Scanner` e exibição da mensagem com `println`
- **Operações Matemáticas:** Cálculo da tabuada usando operações aritméticas simples e uso do laço `for` para percorrer os números de 1 a 10

---

## 🚀 Como Executar

1. Navegue até a pasta deste exercício
2. Compile o arquivo Java:
    
    ```bash
    javac NomeDoArquivo.java
    ```

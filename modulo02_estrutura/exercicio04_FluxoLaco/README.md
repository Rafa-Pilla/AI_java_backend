# 📌 Fluxo de Laço

> **Módulo:** Estrutura de Controle em Java
> 
> 
> **Linguagem:** Java (JDK 21+)
> 

---

## 🎯 Enunciado

Desenvolva um algoritmo onde o usuário escolha um número inicial, e posteriormente informe outros n números até que o último número escolhido dividido pelo primeiro tenha resto diferente de 0.

Obs.: Números menores que o primeiro devem ser ignorados

---

## 💻 Conceitos & Tecnologias Aplicados

- **Entrada e Saída de Dados:** Uso da classe `Scanner` e exibição da mensagem com `println`
- **Operações Matemáticas:** Cálculo de divisão usando operações aritméticas simples, uso de operadores de comparação, uso do laço `do/while` até que a condição desejada seja atendida

---

2. Compile o arquivo Java:

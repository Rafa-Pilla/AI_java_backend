# 📌 Área de um Quadrado

> **Módulo:** Fundamentos da Linguagem de Programação Java
> 
> 
> **Linguagem:** Java (JDK 21+)
> 

---

## 🎯 Enunciado

Desenvolva um algoritmo que receba o tamanho do lado de um quadrado, calcule sua área e exiba o resultado na tela

- fórmula: área = lado * lado

---

## 💻 Conceitos & Tecnologias Aplicados

- **Entrada e Saída de Dados:** Uso da classe `Scanner` e formatação com `printf`
- **Operações Matemáticas:** Cálculo da área do quadrado utilizando o método `Math.pow()`

---

## 🚀 Como Executar

1. Navegue até a pasta deste exercício
2. Compile o arquivo Java:

    ```bash
    javac NomeDoArquivo.java
    ```

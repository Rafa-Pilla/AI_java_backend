# 📌 Cálculo Idade

> **Módulo:** Fundamentos da Linguagem de Programação Java
> 
> 
> **Linguagem:** Java (JDK 21+)
> 

---

## 🎯 Enunciado

Desenvolva um algoritmo que receba o nome e o ano de nascmento do usuário e imprima na tela a mensagem “Olá `nome_uruario` você tem `x` anos”

---

## 💻 Conceitos & Tecnologias Aplicados

- **Entrada e Saída de Dados:** Uso da classe `Scanner` e formatação com `printf`
- **Operações Matemáticas:** Cálculo da idade do usuário usando operações aritméticas simples

---

## 🚀 Como Executar

1. Navegue até a pasta deste exercício
2. Compile o arquivo Java:
    
    ```bash
    javac NomeDoArquivo.java
    ```

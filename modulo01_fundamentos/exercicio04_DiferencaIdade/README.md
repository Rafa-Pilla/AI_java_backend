# 📌 Cálculo da Diferença de Idade entre duas Pessoas

> **Módulo:** Fundamentos da Linguagem de Programação Java
> 
> 
> **Linguagem:** Java (JDK 21+)
> 

---

## 🎯 Enunciado

Desenvolva um algoritmo que receba o nome e a idade de duas pessoas e exiba a diferença de idade entre elas

---

## 💻 Conceitos & Tecnologias Aplicados

- **Entrada e Saída de Dados:** Uso da classe `Scanner` e formatação com `printf`
- **Operações Matemáticas:** Cálculo da diferença  de idade entre os usuários usando operações aritméticas simples e uso do `Math.abs` para manter o valor positivo

---

## 🚀 Como Executar

1. Navegue até a pasta deste exercício
2. Compile o arquivo Java:
    
    ```bash
    javac NomeDoArquivo.java
    ```
